The Home page is the starting point for SoloDevBoard and provides a single entry point into each core feature area.

## Route

`/`

## What You See

The home page shows seven feature panels:

- Audit Dashboard
- Repositories
- One-Click Migration
- Label Manager
- Board Rules Visualiser
- Triage UI
- Workflow Templates

Each panel includes:

- Feature name
- Short description
- Navigation link to the feature route


At present, the Workflow Templates feature page is a placeholder and displays a "coming soon" message while implementation continues. The Board Rules Visualiser and Triage UI are now available to use.

## Navigation

Use the left menu for direct access to:

- Home
- Audit Dashboard
- Repositories
- Migrate
- Labels
- Board Rules
- Triage
- Workflows
