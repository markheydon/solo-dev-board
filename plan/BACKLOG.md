# SoloDevBoard — where work lives

**GitHub Issues are the source of truth** for open, ice-boxed, blocked, and in-progress work. This page is a pointer. It is not a queue, a milestone register, or an ice-box inventory. Do not update it when an issue opens, closes, or changes milestone.

| Resource | What it holds |
|----------|----------------|
| [GitHub Issues (open)](https://github.com/markheydon/solo-dev-board/issues?q=is%3Aissue+is%3Aopen) | The work |
| [SoloDevBoard Roadmap (Project #8)](https://github.com/users/markheydon/projects/8) | Prioritisation, flow, and the Up Next queue |
| [Milestones](https://github.com/markheydon/solo-dev-board/milestones) | The release target, when one is open |
| [`RELEASE_PLAN.md`](RELEASE_PLAN.md) | Versioning, the release runbook, and shipped release notes |
| [`PROJECT_MANAGEMENT.md`](PROJECT_MANAGEMENT.md) | How issues, milestones, and the board are used |
| [`SPEC_KIT_MIGRATION.md`](SPEC_KIT_MIGRATION.md) | How a new or promoted capability is specified |
