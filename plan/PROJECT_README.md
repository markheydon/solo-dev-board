SoloDevBoard provides a single pane of glass for solo developers managing GitHub workloads across multiple repositories.

**Status:** On track. Public releases through [v1.4.0](https://github.com/markheydon/solo-dev-board/releases/tag/v1.4.0) (product chrome, branding, and narrow viewports). **No open milestone** until the next increment is declared ([DEC-027](https://github.com/markheydon/solo-dev-board/blob/main/adr/adr-0027-post-1-0-milestone-and-work-item-hierarchy.md)).
