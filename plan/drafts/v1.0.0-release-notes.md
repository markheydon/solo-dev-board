## SoloDevBoard v1.0.0 — Production Ready

First public release of the six shipped tools, plus hosted GitHub App sign-in and self-host hardening.

Hosted app: https://my.solodevboard.app/
Product site and User Guide: https://solodevboard.com/
Source: https://github.com/markheydon/solo-dev-board

### What is in this release

- **Audit Dashboard** — open issues, pull requests, and workflow health across selected repositories.
- **Label Manager** — create, edit, synchronise, and apply label taxonomies.
- **Repositories** — catalogue repositories available to the signed-in account.
- **One-Click Migration** — copy labels and milestones between repositories.
- **Board Rules Visualiser** — inspect supported GitHub Projects v2 board rules.
- **Triage UI** — keyboard-friendly issue triage, including adding items to a linked board.
- **Workflow Templates** — apply the built-in GitHub Actions template library.
- **Hosted sign-in** — GitHub App OAuth, admission allow-lists, and refresh tokens.
- **Self-host / local** — Aspire orchestration and PAT mode for a trusted personal instance.
- **Deploy** — staging on merge to `main`, production on `v*` tags, to Azure Container Apps.

### Intentionally not in v1.0.0

These are planned, not forgotten:

- Label consistency warnings on the Audit Dashboard (v1.1.0).
- Project board column migration (v1.1.0).
- Custom workflow template repositories (v1.1.0).
- Private user-owned Projects v2 under GitHub App sign-in (v1.1.0; GitHub platform limit).
- Cross-Repo PM Workflow — Daily Focus, Backlog Review, Iteration Planning (v1.2.0).

### Known limitations

- Hosted GitHub App tokens often cannot read **private user-owned** Projects v2 boards. Public boards work. PAT mode with `read:project` is the workaround.
- The public User Guide is published from this tag. Staging About versions keep a `staging` suffix; production About should show `1.0.0`.
