# Progress Reviews

This folder holds dated **PM progress review** artefacts — executive summaries written when you run the [`pm-progress-review`](../../.agents/workflows/pm-progress-review.md) workflow.

**Naming:** Files use `YYYY-MM-DD.md` (ISO date). Titles use **PM Progress Review — {date}**. Older files may still say "Weekly PM Review"; that was the previous naming.

**Cadence:** Reviews are **not** tied to a weekly calendar. Each review covers the period since the newest prior file in this folder (or project inception if none exists). Long gaps between reviews are normal; do not invent filler reviews for idle periods.

**Invocation:** "Run the PM progress review" or `/pm-progress-review`.
