SoloDevBoard is an open-source Blazor Server application for solo developers who manage multiple GitHub repositories.

This section explains where the project came from and how it is built and maintained. For in-app version and runtime details, see the [About page in the User Guide](/docs/about/).

## In this section

- [Origin](/about/origin/) — why SoloDevBoard exists and its lineage from cross-repo PM tooling.
- [How the project is run](/about/how-we-work/) — planning, issues, and AI collaborators in the repository.
